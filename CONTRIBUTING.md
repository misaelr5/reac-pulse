# Contribuir a Reac Pulse

1. Creá una rama con un nombre descriptivo.
2. Mantené HTML semántico y JavaScript sin dependencias innecesarias.
3. Probá el diseño en escritorio y en una pantalla móvil.
4. Usá mensajes de commit claros, preferentemente con Conventional Commits.

Antes de abrir un pull request, verificá que no haya errores en la consola del navegador.
