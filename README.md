# Reac Pulse

Dashboard web responsive para visualizar el estado comercial de una agencia digital.

## Qué incluye

- Resumen de leads, conversiones y facturación estimada.
- Pipeline comercial con estados y prioridades.
- Actividad reciente y próximos seguimientos.
- Filtros por período y modo oscuro premium.
- Diseño responsive para escritorio y celular.

## Tecnologías

HTML semántico, CSS moderno y JavaScript vanilla. No requiere instalación.

## Ejecutar localmente

Abrí `index.html` en el navegador o usá cualquier servidor estático local.

```bash
npx serve .
```

## Estructura

```text
├── index.html   # estructura y contenido
├── styles.css   # sistema visual y responsive
└── app.js       # filtros y navegación
```

El proyecto está pensado como una primera iteración de producto: la interfaz ya funciona con datos de ejemplo y la capa de datos puede reemplazarse por una API cuando exista un backend.

- Conectar datos reales desde una API.
